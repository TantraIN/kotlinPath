## Ye kyun zaruri hai

Jo bhi screen aap bhejte ho wo text hi hai: labels, error messages, formatted prices, log
lines. Java mein iska matlab tha `+` ki lambi chain ya `String.format`. Kotlin ke paas
isse behtar cheez hai, aur yahi pehla Kotlin feature hai jise dekhkar log muskura dete hain.

## Templates: string ke andar `$`

```kotlin title="Templates.kt" numbered runnable
fun main() {
    val name = "Ravi"
    val items = 3

    println("Hello, $name")
    println("You have $items items")
    println("Total: ${items * 250} rupees")   // expression ke liye braces
    println("Name length: ${name.length}")
}
```

Niyam chhota hai: saade variable ke liye `$name`, aur jismein dot, call ya operator ho uske
liye `${...}`. `+` ke bajaye templates chuno — wo waise hi padhte hain jaisa wakya banate
hain.

<Tip bare>
Asli dollar sign print karna ho to escape karo: `"\$5"` `$5` print karta hai.
</Tip>

## Raw strings: escaping ki zarurat hi nahi

Triple quotes har character wahi rakhte hain jo likha hai — newlines, quotes, backslashes.

```kotlin title="Raw.kt" numbered runnable
fun main() {
    val json = """
        {
          "name": "Asha",
          "city": "Pune"
        }
    """.trimIndent()

    println(json)
}
```

`trimIndent()` shuru ki common whitespace hata deta hai, taaki string sirf isliye indented na
rahe kyunki aapka code indented tha. Iske bina har line par aath spaces aa jate.

## Strings immutable hote hain

```kotlin title="Immutable.kt" numbered runnable
fun main() {
    val greeting = "hello"
    val shouted = greeting.uppercase()

    println(greeting)   // hello — nahi badla
    println(shouted)    // HELLO — naya object
}
```

`String` ka har operation naya object lautata hai. `uppercase`, `trim`, `replace` aur `plus`
sab original ko chhedte nahi. Isiliye loop mein `+` se string banana dheema hai — har kadam
par poori nayi string banti hai. Bahut saare tukde jodne hon to `buildString` use karo.

```kotlin title="Building.kt" numbered runnable
fun main() {
    val report = buildString {
        append("Report")
        appendLine()
        repeat(3) { index -> appendLine("row ${index + 1}") }
    }
    println(report)
}
```

## Text compare karna

```kotlin title="Comparing.kt" numbered runnable
fun main() {
    val a = "kotlin"
    val b = "KOTLIN"

    println(a == b)                            // false
    println(a.equals(b, ignoreCase = true))    // true
    println(a.startsWith("kot"))               // true
    println(a.contains("tl"))                  // true
}
```

<Pitfall title="Do jo asli apps mein kaatti hain">
**`===` se compare karna.** `==` contents compare karta hai, `===` identity. Text ke liye
lagbhag hamesha `==` chahiye. Agar aapne strings par `===` likha hai, to wo bug hai.

**Compare karne ke liye user input ko `uppercase()` se case-fold karna.** Turkish mein
`"i".uppercase()` `"I"` nahi hota. Case-insensitive match ke liye
`equals(other, ignoreCase = true)` use karo, jo locale ke hisab se sahi kaam karta hai, text
ko pehle bigadta nahi.
</Pitfall>

## Practice

1. Template se `Asha has 3 unread messages` print karo, naam aur count variables mein
   rakhkar. Phir wahi wakya count dugna karke print karo — template ke andar hi.
2. Ek raw string likho jismein chhota sa SQL query ho aur usmein double quotes hon. Dekho ki
   ek bhi backslash nahi lagana pada.
3. Loop mein `+=` se paanch line ki string banao, phir `buildString` se dobara likho.
   Samjhao kaun sa zyada allocate karta hai aur kyun.
4. `"Hello".replace("l", "L")` — uske baad original variable mein kya pada hai, aur kyun?

## Recap

| Tool | Kis liye |
| --- | --- |
| `"$name"` | Wakya mein variable daalne ke liye |
| `"${expr}"` | Jismein dot, call ya operator ho |
| Triple quotes | JSON, SQL, regex, koi bhi multi-line cheez |
| `.trimIndent()` | Code ne jo indentation di thi use hatane ke liye |
| `buildString { }` | Bahut saare tukde bina kachra banaye jodne ke liye |
| `equals(x, ignoreCase = true)` | Case-insensitive compare, sahi tarike se |
